# Reference board

Drop 8–12 frames here that you would be happy to have made. Name them
`<source>_<what>.png` (e.g. `firewatch_lookout-dusk.png`). The critic scores every still
against a named frame from this folder, so the board *is* the art direction until stills
replace it.

Suggested spread (pick what you actually love, not what fits a theory):

- 3–4 frames in the target family (stylized, strong light, dense): Firewatch, Sable, Journey,
  Tunic, Kena, Ghibli backgrounds.
- 2 frames for **lighting** you want (dusk / ember hour), regardless of style.
- 2 frames for **ground density** — how much clutter and grass reads as "finished".
- 1–2 frames of what you *don't* want, named `anti_<what>.png`, so the critic can name tells.

Reference frames are for private comparison only; don't publish them.
