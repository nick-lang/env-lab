# E06 — Vegetation we made

*Started 2026-09-02. Layer L2. Replaces the E01 procedural kit (icosphere shrubs, lollipop trees, cone grass).*

## Hypothesis

Card-based vegetation, built the way studios build it, beats the procedural kit at 5 m, 50 m and 300 m,
with every part generated by us: a procedural trunk-and-branch generator, leaf and grass **cards** whose
alpha textures come from Flux, and bark tiles from Flux. Pass: you prefer it side by side and it reads at all
three distances. Kill: if cards fail at distance, add imposters; if you still reject it, vegetation becomes
its own project.

## The factory

| Step | Tool | Notes |
|---|---|---|
| Textures | `tools/asset/textures.py cutout` / `tile` | Flux → BiRefNet cutout → RGBA (alpha inverted: ComfyUI's JoinImageWithAlpha treats the mask as transparency) → **edge padding** so masked edges never sample the white background. Tiles get an offset cross-fade to be seamless. Barks are muted afterwards (sat 0.3, brightness 0.6) because the ember sun saturates them. |
| Meshes | `tools/blender/gen_veg.py` + `experiments/06-vegetation/veg_spec.json` | recursive branch growth with taper/jitter/up-bias; crown envelopes (sphere / cone / spread) decide which tips get leaf clusters; clusters are 3–4 cards; shrubs are card balls; grass is 3 crossed cards. Deterministic per species seed. |
| Engine | `tools/ue/ue_import_veg.py` + `build/veg/import.json` | masked, two-sided, two-sided-foliage shading, opacity clip 0.5, subsurface = base × 0.35; bark material from the tile. Meshes in `/Game/Meshes/Veg`. |
| Scene | `world.json` v1 | tree / shrub / grass layers point at the Veg kit with mesh-default materials; rebuilt with `run_e5.py --compile --build --snap --tag E6`. |

Species: **Oak** (11 m, sphere crown, 137 clusters), **Pine** (14 m, cone crown, ~100 clusters), **Hawthorn**
(5.5 m, spread crown, gnarled, berries). Shrubs A/B (card balls), Grass A/B (crossed cards). Textures picked:
`leaf_oak_22`, `leaf_pine_12`, `leaf_hawthorn_1`, `shrub_leaves_12/11`, `grass_tuft_1/2`, `bark_*_muted`.

## Rounds

1. First kit: alpha came out inverted (subject transparent), pine read as white fuzz (pale sparse texture), shrubs
   as stacks of round pads, lineup spot on the map edge.
2. Pine texture denser and darker, pine branches doubled, shrub side-view texture, bark muted, subsurface toned
   down. Grass showed a white fringe (no edge padding); oak read as green blobs (whole-tree texture on cards).
3. Edge padding on every cutout; oak cluster texture; lineup ground label fixed. **Found the builder bug:**
   `new_level` on an existing map keeps its actors, so the level held five stacked copies of the scene and five
   suns — every E05-round-2 and E06 still before this was lit by multiple suns. Builder now wipes; verified 1 sun.
4. Pine branches shortened to stay inside the foliage; bark darkened further; hawthorn clusters fuller.

## Result (round 4) — **passed** (user, 2026-09-02: "It already looks so much better")

Stills: `build/snaps/e6/E6_*.png`, sheet vs E05 `build/snaps/E06_contact_sheet.png`, close-ups
`build/snaps/e6/lineup_veg_cards_5m.png`, procedural for comparison `lineup_veg_procedural_*.png`.

Claude's read: the wide shot is the strongest image the project has produced. Pine and hawthorn read as
species; the hawthorn's berries carry the 5 m view; grass and shrubs stop looking like primitives. Tells left:
cards are visible edge-on up close, oak crowns are still a little blobby, and every bark reads warm under this sun.

## Open items

1. Card clusters need a normal that faces outward for lighting (currently flat card normals → some dark cards).
2. Wind: none. Vertex animation via material later.
3. Imposters / LOD for 300 m and for a 4 km² region (E12).
4. Species count: three is a proof; a biome needs eight to twelve with variants per species.
